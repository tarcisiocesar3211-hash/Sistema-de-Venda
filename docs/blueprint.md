# **App Name**: Sales Glimpse

## Core Features:

- Dashboard Overview: Provides a high-level summary of key sales metrics, visually presented to offer quick insights into performance.
- Client Management: Enables adding, viewing, and managing client information, streamlining customer relationship processes.
- Payment Tracking: Tracks incoming payments, categorizes payment methods, and flags overdue payments for follow-up.
- Invoice Generation: Automates invoice creation and sends invoices directly to clients, with options for customizable templates and branding.

## Style Guidelines:

- Primary color: Deep navy blue (#1A237E), evoking trust and stability.
- Background color: Light grayish-blue (#E8EAF6), providing a clean and professional backdrop.
- Accent color: Vibrant orange (#FF9800) to highlight important actions and key metrics.
- Font pairing: 'Space Grotesk' (sans-serif) for headlines and 'Inter' (sans-serif) for body text, creating a balance of modern and readable elements.
- Use clean, minimalist icons for navigation and representing different data types, ensuring clarity and ease of understanding.
- Dashboard layout with a top navigation bar, incorporating a dropdown menu for easy access to features as per the provided image.
- Subtle transitions and animations to enhance user engagement when loading data or interacting with UI elements.
